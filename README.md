# Daruma ACT model

- Robot: CRANE+ V2
- Simulator: Gazebo
- Policy: ACT
- Task: Daruma otoshi using a hammer attached to the robot hand
- Dataset: selected episodes from the daruma_key_v2 dataset

This model is an experimental result. It does not yet complete the daruma otoshi task reliably.

The checkpoint includes `config.json` and `model.safetensors`.
